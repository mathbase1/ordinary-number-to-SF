Rules of Standard Form
  • Write numbers as a × 10n.
  • a must satisfy 1 ≤ a < 10.
  • n is an integer:
    • n > 0 when the original number > 1 (decimal moves left).
    • n < 0 when the original number < 1 (decimal moves right).
